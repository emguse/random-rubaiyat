# Requirements

## Goal

利用者がインストールせず、Webブラウザから小川亮作訳『ルバイヤート』の一首に出会えるようにする。

「どこでもアクセスできる」とは、初期リリースではインターネットに接続された一般的なブラウザから公開URLを開けることを指す。オフライン動作は含めない。

## Functional requirements

### FR-1: Initial load

- ページを開くと作品データを一度だけ読み込む。
- 読み込みが完了するまで、作品選択ボタンを操作できないようにする。
- 読み込みに失敗した場合は、利用者に理解できるエラーを表示する。

### FR-2: Random poem

- 全作品を候補として、一首を一様にランダム選択する。
- データのIDが連続していることを実行時の前提にしない。

### FR-3: Random booze-ism poem

- `is_boozeism` が真の作品だけを候補として、一首を一様にランダム選択する。
- 候補集合はデータ読み込み後に一度だけ作る。

### FR-4: Rendering

- 作品番号、章、本文を表示する。
- 脚注がある場合だけ脚注を表示する。
- 原文の改行を保持する。
- 作品データをHTMLとして解釈しない。

### FR-5: Attribution

- 原作者、訳者、底本データの出典をサイト内から確認できるようにする。

## Non-functional requirements

- サーバーサイドのアプリケーションを必要としない。
- JavaScriptフレームワークや実行時依存を必要としない。
- モバイル幅でも横スクロールなしで主要操作と本文を閲覧できる。
- マウスなしでボタンを操作でき、フォーカス位置を視認できる。
- データ取得後の作品選択でネットワーク通信を発生させない。
- GitHub Pagesのプロジェクトサイトで動く相対URLを使用する。

## Initial data invariants

移行元データを取り込む時点で、少なくとも次を検証する。

- 全143件
- IDは重複しない
- 酒に関係する作品は71件
- 章は8種類
- 脚注付き作品は32件
- 必須の本文と章は空でない

これらは移行時点の既知値であり、将来データを正式に改訂する場合は、データと検証値を同じ変更で更新する。

## Out of scope

- 検索、並べ替え、章別閲覧
- タグ、お気に入り、閲覧履歴
- ログイン、同期、投稿
- オフライン対応、Service Worker、PWA
- アクセス解析、広告
- デスクトップアプリケーションの配布
- 独自API、データベース、管理画面

## Acceptance criteria

- 2種類のランダム選択が、定義された候補集合だけから作品を返す。
- 143件の本文、メタデータ、脚注が変換前データと一致する。
- JavaScriptを有効にした主要なモバイル／デスクトップブラウザで操作できる。
- ローカルHTTPサーバーと本番の静的ホスティングで同じ相対パスが動作する。
- 静的ホスティング上でPython、SQLite、環境変数を必要としない。
